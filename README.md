# TaskFlow - Gerenciador de Tarefas


Projeto acadêmico para gerenciamento simples de tarefas diárias.


## Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript
* conflito de merge: git merge, modificado a mesma linha de um mesmo arquivo.

## Estrutura de Pastas
* `src/`: Arquivos do código fonte (HTML, CSS e JS)
* `docs/`: Documentação e requisitos do projeto
* `assets/`: Recursos visuais

## Integrantes
* Integrante 1 - Configuração inicial do repositório e arquivos base
* Integrante 2 - Desenvolvimento da interface (HTML e CSS)
* Integrante 3 - Implementação da lógica (JS) e documentação de requisitos
